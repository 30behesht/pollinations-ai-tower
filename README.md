# AI Tower

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

Build and manage your own tower of AI-run company departments. Each floor generates isometric art and runs autonomous work sprints powered by Pollinations text and image models with `<polli-connect>`.

- **Live App:** https://30behesht.github.io/pollinations-ai-tower/
